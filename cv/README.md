# CV drop folder

Place your CV as a PDF here, e.g. `cv/resume.pdf`.

The file itself is gitignored (see root `.gitignore`) — it's a personal document and
isn't committed. Once it's here, ask Claude Code to read it and populate
`prisma/seed.ts` (and, if relevant, `prisma/schema.prisma`) with your real profile,
skills, projects and experience. See the root `CLAUDE.md` for the exact rule this
follows.
